Un **dataset de Kaggle** es un conjunto de datos estructurados, semiestructurados o no estructurados que se encuentran alojados en la plataforma Kaggle, la cual es una comunidad global de científicos de datos y entusiastas del *machine learning*.

Estos datasets son el punto de partida fundamental ("el cimiento") para el desarrollo de proyectos de análisis de datos. Aquí te detallo qué los caracteriza:

* 
**Diversidad de temas**: Contienen información sobre diversas áreas como finanzas, salud o marketing.

* 
**Utilidad práctica**: Permiten transformar datos crudos en historias visuales o modelos predictivos.

* 
**Características técnicas**: Para ser efectivos, especialmente en proyectos de nivel 2, los datasets ideales deben contar con dimensiones temporales y categóricas que faciliten el análisis de tendencias.

* **Ejemplos comunes**:
**** USARERMOS: E-Commerce Sales ****

* 
**e-Commerce Sales**: Útiles para analizar ventas por mes o categoría.

* 
**Netflix Movies & TV Shows**: Ideales para observar el crecimiento de contenido por año o país.

* 
**Global Cryptocurrency Prices**: Utilizados para estudiar tendencias de precios y volatilidad.


En resumen, un dataset de Kaggle es una herramienta de aprendizaje y experimentación que permite a los usuarios poner en práctica etapas como la ingesta, limpieza, análisis exploratorio (EDA) y visualización de datos.

Para obtener el archivo `ecommerce_sales.csv` (o cualquier dataset similar para tus proyectos de Ciencia de Datos), la fuente principal y más recomendada es **Kaggle**. Aquí te explico cómo conseguirlo:

### Pasos para obtener el dataset:

1. 
**Ingresa a Kaggle:** Visita [kaggle.com](https://www.kaggle.com/). Si no tienes una cuenta, deberás crear una de forma gratuita.

2. 
**Utiliza el buscador:** En la barra de búsqueda de la página principal, escribe términos como `"e-Commerce Sales"` o `"Sales Data"`.

3. **Filtra por tipo:** En el menú de resultados, puedes filtrar para ver solo **"Datasets"**.
4. **Selecciona el archivo:** Busca uno que tenga archivos en formato `.csv` (que son los que Pandas puede leer directamente).
* 
*Nota:* Asegúrate de que el dataset tenga columnas de **fecha** y **categorías**, ya que son fundamentales para realizar el análisis de tendencias que requiere tu Proyecto de Nivel 2.

5. **Descarga:** Haz clic en el botón **"Download"** (generalmente ubicado en la parte superior derecha de la página del dataset). Esto descargará un archivo comprimido (`.zip`) que, al extraerlo, contendrá tu archivo `ecommerce_sales.csv`.

### 1. Ingesta y Limpieza (Pandas)

Con columnas como `Discount` y `Profit`, es vital asegurar que sean numéricas para poder realizar cálculos financieros precisos.

```python
import pandas as pd

df = pd.read_csv("ecommerce_sales_details.csv")

# Convertir fechas y asegurar tipos numéricos
df['Order Date'] = pd.to_datetime(df['Order Date'])
cols_numericas = ['Quantity', 'Unit Price', 'Discount', 'Sales', 'Profit']
df[cols_numericas] = df[cols_numericas].apply(pd.to_numeric)

```

* **Análisis de Descuentos:** ¿Los descuentos altos están afectando el `Profit` final?

```python
# Calcular margen de beneficio
df['Profit Margin'] = (df['Profit'] / df['Sales']) * 100

# Análisis rápido: Profit por Categoría
profit_por_cat = df.groupby('Category')['Profit'].sum().reset_index()
```

### 5. Despliegue con Interactividad (Streamlit)

Aquí es donde aplicamos el **Drill-down** solicitado.

#
# Se requiere instalación en el entorno virtual de 
# la dependencia. 
# No se puede ejecutar desde el IDLE o Jupyter. Debe
# correrse como aplicación, ejecutando desde el prompt
# el comando:

#
# https://streamlit.io/

# > streamlit run app.py

```python
import streamlit as st

st.title("Dashboard Ejecutivo de Ventas")

# Filtros laterales
region = st.sidebar.selectbox("Selecciona Región:", df['Region'].unique())
modo_pago = st.sidebar.selectbox("Modo de Pago:", df['Payment Mode'].unique())

# Filtrado dinámico
df_f = df[(df['Region'] == region) & (df['Payment Mode'] == modo_pago)]

# Métricas clave (KPIs)
col1, col2 = st.columns(2)
col1.metric("Ventas Totales", f"${df_f['Sales'].sum():,.2f}")
col2.metric("Ganancia Total", f"${df_f['Profit'].sum():,.2f}")

# Gráfico de tendencia filtrado
st.line_chart(df_f.groupby('Order Date')['Sales'].sum())

```
