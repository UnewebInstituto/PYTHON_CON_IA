### 1. Teoría: ¿Qué es una Red Neuronal Artificial (Perceptron)?

Una RNA está inspirada en la estructura biológica de las neuronas del cerebro. Se compone de capas de "neuronas" interconectadas:

* 
**Capa de Entrada (Input Layer):** Recibe los datos crudos (ej. las 105 características morfológicas y de color de tus granos de arroz).


* **Capas Ocultas (Hidden Layers):** Es donde ocurre el "aprendizaje". Cada neurona aplica una función matemática (peso y sesgo) a los datos de entrada para extraer características cada vez más abstractas.

* 
**Capa de Salida (Output Layer):** Entrega el resultado final (ej. la probabilidad de que un grano sea "Basmati" o "Premium").

* **TensorFlow:** Es una plataforma de código abierto desarrollada por Google para el aprendizaje automático de extremo a extremo. Proporciona el motor computacional necesario para realizar operaciones matemáticas complejas (tensores) sobre grandes volúmenes de datos.

### 2. Práctica: Construcción de una red con Keras

Para aplicar esto, vamos a crear una red neuronal sencilla que reemplace tu `RandomForestClassifier`. Esta red será capaz de clasificar granos de arroz basándose en los datos limpios que ya procesas en tus scripts actuales.

---

# --- Dependencias necesarias ---
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Dropout
import matplotlib.pyplot as plt
from google.colab import drive

# 1. Montaje de Drive y Carga de datos
drive.mount('/content/drive')
df = pd.read_csv('/content/drive/MyDrive/data/Rice_MSC_Dataset.csv')

# 2. Función de limpieza (basada en tu lógica original)
def limpiar_lote(df):
    for col in df.columns:
        if df[col].isnull().sum() > 0:
            df[col] = df[col].fillna(df[col].mean())
    return df.drop_duplicates()

df = limpiar_lote(df)

# 3. Ingeniería de Variable Objetivo (Target Binario)
df['Calidad_Aceptable'] = np.where(df['CLASS'] == 'Basmati', 1, 0)
X = df.drop(columns=['CLASS', 'Calidad_Aceptable'])
y = df['Calidad_Aceptable']

# 4. Preparación de datos para la Red Neuronal
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X) # Escalamos las características para la Red Neuronal

# División de datos
X_train_s, X_test_s, y_train_s, y_test_s = train_test_split(
    X_scaled, y, test_size=0.3, stratify=y, random_state=42
)

# 5. Construcción de la Red Neuronal (Keras)
model = Sequential([
    Dense(128, activation='relu', input_shape=(X_train_s.shape[1],)),
    Dropout(0.2),
    Dense(64, activation='relu'),
    Dense(1, activation='sigmoid')
])

model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

# 6. Entrenamiento
print("\n--- Entrenando Red Neuronal ---")
history = model.fit(X_train_s, y_train_s, epochs=20, batch_size=32, validation_split=0.2, verbose=0)

# 7. Evaluación
loss, acc_nn = model.evaluate(X_test_s, y_test_s, verbose=0)
print(f"Precisión (Accuracy) del modelo Red Neuronal: {acc_nn:.4f}")

# Visualización
plt.plot(history.history['accuracy'], label='Entrenamiento')
plt.plot(history.history['val_accuracy'], label='Validación')
plt.title('Progreso de aprendizaje de la Red Neuronal')
plt.xlabel('Época')
plt.ylabel('Precisión')
plt.legend()
plt.show()

### 3. Descripción del código:

Este código es una implementación completa para integrar una Red Neuronal Artificial (RNA) en tu flujo de trabajo, permitiendo una comparativa directa con tu modelo de *RandomForest*.

Aquí tienes la descripción de cada parte:

### 1. Preparación de datos (Preprocesamiento)

* **`StandardScaler`**: Las redes neuronales son sensibles a la escala (ej. no es lo mismo "peso" que "área"). Este escalador transforma tus datos para que tengan una media de 0 y una desviación estándar de 1, facilitando el aprendizaje.

1. Media de 0 (Centrado)
¿Qué significa? Es el valor promedio de cada columna después de la transformación.

En la práctica: Si una característica (por ejemplo, el "Perímetro" del grano) tiene valores que van de 500 a 800, el escalador resta el promedio a cada dato. Esto mueve la "nube" de puntos hacia el centro del sistema de coordenadas (el cero).

Por qué ayuda: Esto evita que el modelo de red neuronal se "confunda" con valores muy grandes o muy pequeños, permitiendo que los pesos de las neuronas se ajusten más rápido.

2. Desviación Estándar de 1 (Escalamiento)
¿Qué significa? Es una medida de cuánto se dispersan los datos respecto a la media.

En la práctica: Una vez que los datos están centrados en 0, el escalador divide cada valor por su desviación estándar. Esto "estira" o "comprime" los datos para que el 68% de ellos (aproximadamente) caiga dentro del rango de -1 a 1.

Por qué ayuda: Esto pone todas tus variables en un "terreno de juego nivelado".

¿Por qué esto es vital para las Redes Neuronales?
Imagina que una neurona recibe dos entradas de tu dataset de arroz:

Área: Un número como 2000.

Color (valor de contraste): Un número como 0.05.

Como la red neuronal multiplica estos valores por "pesos", si no los escalas, la neurona le dará muchísima más importancia al "Área" simplemente porque el número es más grande, aunque el "Color" sea igual de importante para la calidad.

En resumen:
Al estandarizar, conviertes todas tus 105 variables en una escala común y comparable. Esto hace que la función de activación (relu en tu código) y el optimizador (adam) trabajen de forma mucho más eficiente, porque la red no tiene que esforzarse en compensar la diferencia de magnitud entre las variables. Es como si en lugar de comparar "peras con manzanas", convirtieras todo a "unidades de calidad estándar".

* **`fit_transform(X)`**: Calcula los parámetros de normalización y aplica la transformación a todo el dataset.

* **`train_test_split`**: Divide tus datos escalados en conjuntos de entrenamiento y prueba, manteniendo la proporción original de las clases (estratificación), tal como hacías en tu script original.

### 2. Construcción de la Red Neuronal (Arquitectura)

* **`Sequential`**: Define una red donde las capas están apiladas una tras otra de forma lineal.
* **`Dense(128, activation='relu')`**: Primera capa oculta con 128 neuronas. La función `relu` permite a la red aprender patrones complejos no lineales.
* **`Dropout(0.2)`**: Técnica de regularización que "apaga" aleatoriamente el 20% de las neuronas durante el entrenamiento. Esto es vital para evitar el *overfitting* (que el modelo memorice el dataset en lugar de aprender patrones generales).
* **`Dense(1, activation='sigmoid')`**: Capa de salida. Al ser una clasificación binaria (¿es Basmati o no?), la función `sigmoid` devuelve un valor entre 0 y 1 (probabilidad).

### 3. Configuración y Entrenamiento

* **`model.compile`**: Define cómo aprenderá la red:
* `optimizer='adam'`: El algoritmo que ajusta los pesos de la red automáticamente.
* `loss='binary_crossentropy'`: La función de pérdida estándar para clasificación de dos clases.


* **`model.fit`**: Aquí ocurre la "magia". El modelo recorre los datos `20` veces (`epochs`) en paquetes de `32` muestras (`batch_size`). El `validation_split=0.2` reserva automáticamente una parte de los datos para monitorear qué tan bien aprende el modelo en tiempo real.

### 4. Evaluación y Comparación

* **`model.evaluate`**: Calcula el desempeño final del modelo usando los datos de prueba (`X_test_s`), que nunca fueron vistos durante el entrenamiento.
* **Comparación (`score_rf`)**: Llama al método de tu modelo `RandomForest` original para obtener su precisión y contrastarla con la de la red neuronal.

### 5. Visualización del Entrenamiento

* **`history.history`**: Accede a los registros de precisión (`accuracy`) almacenados durante las 20 épocas.
* **`plt.plot`**: Genera una gráfica que compara la precisión en el entrenamiento vs. la validación. Si ves que la línea de "Entrenamiento" sube y la de "Validación" baja, sabrás que tu modelo está sufriendo *overfitting*.

KERAS

///
**Keras** es una biblioteca de **redes neuronales de código abierto** escrita en Python, diseñada específicamente para ser una interfaz amigable, intuitiva y fácil de usar para construir modelos de inteligencia artificial.

Actualmente, Keras es la API oficial de alto nivel integrada directamente en **TensorFlow**, la plataforma de computación de Google para aprendizaje automático.

### ¿Por qué es tan popular?

* **Facilidad de uso:** Fue diseñado para seres humanos, no para máquinas. Su sintaxis es clara y directa, lo que permite pasar de una idea a un modelo funcional en muy pocas líneas de código.
* **Modularidad:** Keras trata a las redes neuronales como un conjunto de bloques de construcción (capas, funciones de activación, optimizadores) que puedes "enchufar" y combinar de forma sencilla, tal como vimos en tu modelo para el proyecto.
* **Versatilidad:** Aunque es sencillo, es extremadamente potente. Permite desde modelos secuenciales simples (como tu red de clasificación de arroz) hasta arquitecturas de aprendizaje profundo muy complejas.

### ¿Cómo encaja en tu trabajo?

Cuando usas código como `tf.keras.layers.Dense` o `Sequential`, estás utilizando Keras para:

1. **Abstracción:** Keras se encarga de todo el cálculo matemático complejo "bajo el capó" (como la propagación hacia atrás o el cálculo de gradientes) para que tú te enfoques en diseñar la lógica del modelo.
2. **Integración:** Al ser parte del ecosistema de TensorFlow, puedes aprovechar toda su infraestructura para escalar tus modelos, guardarlos en formatos como `.keras` y desplegarlos en producción.

En resumen, Keras es el "puente" que te permite implementar matemáticas avanzadas de forma estructurada, permitiendo que tu asistente inteligente aprenda patrones de calidad en los datos de arroz de manera eficiente.

1. Clasificación Multi-Clase (Más allá del Basmati)
Actualmente clasificas como "Basmati" o "Otros". Un ejemplo práctico es modificar tu modelo para clasificar las variedades reales que existen en tu dataset (ej. Arborio, Jasmine, Basmati, Ipsala, etc.).

Cambio en Keras: Cambiar la última capa de Dense(1, activation='sigmoid') a Dense(N_clases, activation='softmax'), donde N es el número de variedades.

Utilidad: Permite que tu asistente inteligente identifique automáticamente la variedad de arroz de un lote y ajuste los parámetros de calidad en consecuencia.

////

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from google.colab import drive
from sklearn.preprocessing import StandardScaler, LabelEncoder
from sklearn.model_selection import train_test_split
from sklearn.metrics import confusion_matrix, classification_report
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Dropout
from tensorflow.keras.utils import to_categorical

# 1. Carga de datos desde Drive
drive.mount('/content/drive')
df = pd.read_csv('/content/drive/MyDrive/data/Rice_MSC_Dataset.csv')

# 2. Limpieza (Lógica de tu proyecto)
def limpiar_lote(df):
    for col in df.columns:
        if df[col].isnull().sum() > 0:
            df[col] = df[col].fillna(df[col].mean())
    return df.drop_duplicates()

df = limpiar_lote(df)

# 3. Preparación Multi-clase
le = LabelEncoder()
df['CLASS_encoded'] = le.fit_transform(df['CLASS'])

X = df.drop(columns=['CLASS', 'CLASS_encoded', 'Calidad_Aceptable'], errors='ignore')
y = to_categorical(df['CLASS_encoded'])

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.3, random_state=42)

# 4. Modelo Multi-clase
model = Sequential([
    Dense(128, activation='relu', input_shape=(X_train.shape[1],)),
    Dropout(0.3),
    Dense(64, activation='relu'),
    Dense(y.shape[1], activation='softmax') # Softmax para múltiples clases
])

model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])
model.fit(X_train, y_train, epochs=30, batch_size=32, verbose=0)

# 5. Generación de resultados: Matriz de Confusión
predicciones = model.predict(X_test)
clases_reales = np.argmax(y_test, axis=1)
clases_predichas = np.argmax(predicciones, axis=1)

cm = confusion_matrix(clases_reales, clases_predichas)
plt.figure(figsize=(8, 6))
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
            xticklabels=le.classes_, yticklabels=le.classes_)
plt.title('Matriz de Confusión: Clasificación por Variedad')
plt.ylabel('Real')
plt.xlabel('Predicho')
plt.show()

Descripción:

///

Este código es una implementación para clasificar granos de arroz en múltiples variedades (no solo "Basmati" vs "Otros"). El flujo integra la carga de datos, limpieza, preprocesamiento estadístico, entrenamiento de una red neuronal profunda y evaluación mediante una matriz de confusión.

Aquí tienes el desglose técnico de sus componentes:

### 1. Ingesta y Limpieza de Datos

* **`drive.mount` y `pd.read_csv**`: Conecta el entorno con Google Drive para importar el dataset directamente desde la carpeta `/data`.
* **`limpiar_lote(df)`**: Ejecuta una limpieza robusta. Itera sobre las columnas, sustituyendo valores nulos por la media aritmética de cada columna y eliminando filas duplicadas para evitar sesgos en el entrenamiento.

### 2. Ingeniería de Características (Preparación Multi-clase)

* **`LabelEncoder`**: Transforma los nombres de las variedades de arroz (texto) en etiquetas numéricas (ej. 0, 1, 2).
* **`to_categorical`**: Aplica *One-Hot Encoding*. Convierte las etiquetas numéricas en vectores binarios, permitiendo que la red neuronal procese cada clase de forma independiente.
* **`StandardScaler`**: Estandariza las características de entrada. Esto es crítico para que las neuronas asignen pesos equilibrados a variables con distintas escalas (como peso, perímetro o área).

### 3. Arquitectura de la Red Neuronal (Deep Learning)

* **`Sequential`**: Define una arquitectura de capas apiladas linealmente.
* **Capas Ocultas (`Dense`)**:
* La primera capa tiene **128 neuronas** con activación `ReLU`, ideal para detectar relaciones no lineales complejas entre los 105 atributos del arroz.
* La segunda capa de **64 neuronas** refina las características extraídas.

* **`Dropout(0.3)`**: Actúa como un regulador. "Apaga" el 30% de las conexiones de forma aleatoria durante cada paso del entrenamiento, forzando al modelo a aprender patrones generales en lugar de memorizar el dataset (*overfitting*).
* **Capa de Salida (`softmax`)**: Utiliza `softmax` para generar una distribución de probabilidad que suma 1.0, permitiendo clasificar entre múltiples variedades simultáneamente.

### 4. Optimización y Evaluación

* **`categorical_crossentropy`**: Función de pérdida óptima para problemas donde se clasifica en más de dos categorías.
* **`confusion_matrix` y `heatmap**`: Esta sección es vital para el control de calidad. Visualiza cuántas muestras de cada variedad fueron correctamente clasificadas y cuáles fueron confundidas por el modelo, permitiendo identificar qué variedades son más difíciles de diferenciar físicamente.

Este diseño no solo es más potente que un modelo tradicional, sino que ofrece una trazabilidad técnica superior al permitir ver cómo se distribuyen los errores entre las distintas variedades de arroz.
