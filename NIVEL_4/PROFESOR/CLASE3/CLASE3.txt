### **1. Marco Teórico: De las Palabras a la Emoción**

El NLP convierte el texto "sucio" (lenguaje natural) en estructuras matemáticas que una computadora puede procesar.

* **Limpieza de Texto (Preprocesamiento):** El texto real está lleno de ruido. El objetivo es normalizar los datos:
* **Tokenización:** Dividir frases en palabras individuales o "tokens".
* **Normalización:** Convertir todo a minúsculas, eliminar signos de puntuación, URLs y números.
* **Stopwords Removal:** Eliminar palabras irrelevantes para el sentimiento (ej. "el", "la", "de", "que"), que no aportan significado emocional.
* **Lematización/Stemming:** Reducir palabras a su raíz (ej. "arrozal", "arroces" -> "arroz").

* **Análisis de Sentimiento:** Es una técnica de clasificación. El modelo recibe un texto y asigna un "score" (valor) para determinar si es **Positivo, Negativo o Neutro**. Se basa en diccionarios de palabras con polaridad o en redes neuronales (modelos de lenguaje) que entienden el contexto.

Aquí te detallo cómo funciona realmente `TextBlob` y por qué tiene esas limitaciones:

### 1. El límite del soporte de idiomas

`TextBlob` se basa principalmente en la librería **NLTK** (Natural Language Toolkit) y en **Pattern**.

* **Inglés:** Es su idioma "nativo". El análisis de sentimiento, la lematización y el etiquetado gramatical funcionan excelente porque utiliza diccionarios y modelos entrenados específicamente para inglés.
* **Otros idiomas (Español, Francés, Alemán, etc.):** `TextBlob` tiene soporte para otros idiomas, pero es **muy limitado**.
* Puedes crear un objeto `TextBlob("Hola, ¿cómo estás?", hint='es')`, pero muchas de sus funcionalidades avanzadas (como la detección de sentimiento basada en polaridad) están hardcodeadas para el inglés.

### 2. El problema del Análisis de Sentimiento

La función `analisis.sentiment.polarity` de `TextBlob` funciona buscando palabras en un **diccionario de sentimientos** predefinido.

* Ese diccionario está escrito en **inglés**.
* Si intentas analizar una frase en español, es muy probable que `TextBlob` no encuentre ninguna de las palabras en su diccionario, devolviéndote siempre un valor de `0.0` (neutro), sin importar si la frase es positiva o negativa.

Para empezar rápido, utilizaremos `TextBlob`, una librería intuitiva para NLP en Python.

```python
# Instalación: pip install textblob
from textblob import TextBlob

# 1. Función de limpieza básica
def limpiar_texto(texto):
    # Convertir a minúsculas y quitar caracteres no alfabéticos simples
    texto = texto.lower()
    return texto

# 2. Análisis de sentimiento
comentarios = [
    "El arroz tiene una calidad excelente, muy blanco y limpio.",
    "El producto es aceptable, pero llegó con algunas impurezas.",
    "Pésima experiencia, el arroz estaba lleno de granos rotos."
]

for c in comentarios:
    texto_limpio = limpiar_texto(c)
    analisis = TextBlob(texto_limpio)
    
    # 'polarity' va de -1 (negativo) a 1 (positivo)
    score = analisis.sentiment.polarity
    sentimiento = "Positivo" if score > 0 else "Negativo" if score < 0 else "Neutro"
    
    print(f"Texto: {c}\nSentimiento: {sentimiento} (Score: {score:.2f})\n")

```

### 2. Pipeline de entrenamiento (Práctica)

Utilizaremos `Scikit-Learn`, la librería estándar para modelos de clasificación clásica.

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline

# 1. Dataset de ejemplo (en producción, esto vendría de un archivo .csv)
datos = [
    ("grano partido y con impurezas", 0),
    ("arroz de primera, muy blanco", 1),
    ("contiene muchos granos yesosos", 0),
    ("aspecto cristalino y granos enteros", 1)
]
textos, etiquetas = zip(*datos)

# 2. Pipeline: Vectorización (Convertir texto a números) + Clasificador (Naive Bayes)
# TfidfVectorizer: Da importancia a palabras técnicas específicas ("yesoso")
# eliminando las comunes ("el", "de").
model = make_pipeline(TfidfVectorizer(), MultinomialNB())

# 3. Entrenamiento
model.fit(textos, etiquetas)

# 4. Predicción
nuevo_comentario = ["el arroz tiene muchas impurezas"]
resultado = model.predict(nuevo_comentario)
print(f"Predicción (1=Alta, 0=Baja): {resultado[0]}")

```

### 3. ¿Por qué este enfoque es superior para el proyecto?

1. **Contexto técnico:** A diferencia de `TextBlob` (que usa un diccionario generalista), este modelo aprende que la palabra "yesoso" (término técnico arrocero) es una característica negativa.
2. **Aprendizaje supervisado:** Tú decides qué define una "buena calidad". Si en tu planta de arroz consideran que un 5% de granos rotos es aceptable, puedes ajustar las etiquetas de tu dataset para que el modelo aprenda tus estándares exactos.
3. **Escalabilidad:** Puedes empezar con 100 ejemplos y, a medida que pase el tiempo, alimentar el modelo con miles de reseñas reales de tus clientes, haciendo que sea cada vez más preciso.

### Script de Etiquetado con Validación Profesional

```python
import pandas as pd
import os

#ruta_csv = '/content/drive/MyDrive/data/dataset_arroz.csv'
ruta_csv = 'dataset_arroz.csv'

def agregar_reseña():
    # 1. Cargar o crear el CSV
    if os.path.exists(ruta_csv):
        df = pd.read_csv(ruta_csv)
    else:
        df = pd.DataFrame(columns=['id', 'texto_original', 'categoria_tecnica', 'polaridad', 'fuente'])

    print("--- Nuevo Etiquetado (Proyecto Data Collector) ---")
    
    # 2. Validación de Texto (No vacío)
    while True:
        texto = input("Escribe la reseña del cliente: ").strip()
        if len(texto) > 5: # Validamos longitud mínima para evitar errores
            break
        print("Error: La reseña es muy corta o está vacía. Inténtalo de nuevo.")

    cat = input("Categoría (ej: aspecto, sabor, limpieza): ").strip()
    
    # 3. Validación de Polaridad (Solo 0 o 1)
    while True:
        pol = input("¿Es positiva (1) o negativa (0)?: ").strip()
        if pol in ['0', '1']:
            polaridad = int(pol)
            break
        print("Error: Debes ingresar solo 0 o 1.")
    
    # 4. Crear nueva fila
    nuevo_id = df['id'].max() + 1 if not df.empty else 1
    nueva_fila = {
        'id': nuevo_id,
        'texto_original': texto,
        'categoria_tecnica': cat,
        'polaridad': polaridad,
        'fuente': 'manual_proyecto'
    }
    
    # 5. Guardado seguro
    df = pd.concat([df, pd.DataFrame([nueva_fila])], ignore_index=True)
    df.to_csv(ruta_csv, index=False)
    
    print(f"\n✅ Reseña {nuevo_id} guardada con éxito.")

# Ejecutar
agregar_reseña()

```

### ¿Qué mejoras hemos implementado?

* **`strip()`:** Elimina espacios accidentales al principio o al final de lo que escribes.
* **Validación de longitud (`len(texto) > 5`):** Evita que guardes etiquetas accidentales o texto vacío que no sirve para entrenar a la IA.
* **Validación de tipo (`pol in ['0', '1']`):** Evita que escribas una palabra por error (como "bueno") en lugar de un número, lo cual rompería tu código de entrenamiento después.
* **Bucle `while True`:** Obliga al usuario (tú) a corregir el error antes de proceder, garantizando que cada entrada en tu CSV sea de **alta calidad**.

```python
# Primero, instala la librería: pip install transformers torch


from transformers import pipeline

# 1. Cargamos un pipeline de análisis de sentimiento
# Este modelo es multilingüe y funciona excelente con español
classifier = pipeline("sentiment-analysis", model="pysentimiento/robertuito-sentiment-analysis")

# 2. Definimos nuestras reseñas sobre el arroz
comentarios = [
    "El grano de arroz está excelente, muy blanco y con gran textura.",
    "Estoy muy decepcionado, el producto llegó con muchas impurezas y restos de cascarilla.",
    "El arroz es aceptable, el sabor es estándar."
]

# 3. Clasificación
for c in comentarios:
    resultado = classifier(c)
    print(f"Texto: {c}")
    print(f"Sentimiento: {resultado[0]['label']}, Confianza: {resultado[0]['score']:.2f}\n")

```

### ¿Por qué este modelo es superior para " "?

1. **Contexto Cultural:** A diferencia de `TextBlob`, que traduce y pierde significado, este modelo (`robertuito`) fue entrenado con millones de tuits y textos en español, por lo que entiende jerga, emojis y estructuras gramaticales complejas del español.
2. **Confianza Probabilística:** El modelo no solo te dice "Positivo" o "Negativo", sino que te devuelve un **score de confianza**.
* *Ejemplo:* Si el modelo dice "Negativo" con 0.99 de confianza, puedes confiar ciegamente. Si dice "Positivo" con 0.51, podrías programar el sistema para que marque esa reseña para revisión humana (gestión de excepciones).


3. **Velocidad de Inferencia:** `robertuito` es un modelo basado en RoBERTa, optimizado para ser rápido, lo cual es ideal si planeas integrar esto en una web o app donde el usuario espera una respuesta en tiempo real.

Para entender el estado actual de la Inteligencia Artificial, es necesario distinguir entre la **arquitectura** (la estructura lógica) y el **motor** (la herramienta de computación). **Transformers** y **PyTorch** son las dos piezas que, al unirse, han permitido el auge de los modelos modernos como los que se usan en nuestro proyecto.

---

### 1. ¿Qué son los Transformers? (La Arquitectura)

Introducidos en 2017 por Google, los **Transformers** revolucionaron la IA al resolver el problema de la "memoria" en los modelos de lenguaje.

* **El problema anterior:** Antes, modelos como las RNN (Redes Neuronales Recurrentes) procesaban el texto palabra por palabra, de forma secuencial. Si una frase era larga, el modelo olvidaba el inicio al llegar al final.
* **La solución - "Atención" (Attention Mechanism):** Los Transformers procesan toda la secuencia de texto **simultáneamente**. Gracias a una técnica llamada *Auto-atención* (Self-Attention), el modelo puede "mirar" todas las palabras de una oración al mismo tiempo y decidir cuáles son más importantes para entender el contexto.
* *Ejemplo:* En la frase *"El arroz que compré estaba húmedo porque **él** se mojó"*, el Transformer sabe instantáneamente que "**él**" se refiere al "**arroz**", sin importar qué tan lejos estén en la oración.

### 2. ¿Qué es PyTorch? (El Motor de Computación)

PyTorch es una librería de **código abierto** desarrollada por el laboratorio de IA de Meta (Facebook). Es el entorno de desarrollo donde realmente se "construyen" y "entrenan" los modelos como los Transformers.

* **Cálculo de Tensores:** Así como `Numpy` trabaja con arreglos, PyTorch trabaja con **tensores** (matrices multidimensionales). Lo especial de PyTorch es que estos tensores pueden residir en la memoria de una **GPU** (tarjeta gráfica), lo que permite realizar miles de millones de cálculos matemáticos por segundo.
* **Autograd (Gradiente Automático):** Esta es la joya de la corona. PyTorch calcula automáticamente las derivadas matemáticas necesarias para el *Backpropagation* (el proceso mediante el cual una IA aprende de sus errores). Sin esto, tendrías que calcular manualmente miles de ecuaciones complejas cada vez que quieras mejorar tu modelo.
* **Dinámico vs. Estático:** PyTorch es conocido por su **grafo de computación dinámico**. Esto significa que puedes modificar el comportamiento de la red neuronal "sobre la marcha" mientras se ejecuta, lo cual es mucho más intuitivo para los investigadores y desarrolladores.

Para entender el corazón de los Transformers, debemos ver la **Atención escalada por producto punto** (*Scaled Dot-Product Attention*). Esta es la función matemática que permite al modelo decidir a qué palabras "prestar atención" dentro de una oración.

A nivel de código, esto se traduce en operaciones matriciales con tensores. Aquí tienes una implementación simplificada utilizando **PyTorch**.

### Script: Capa de Atención Simple

```python
import torch
import torch.nn.functional as F
import math

def scaled_dot_product_attention(query, key, value):
    """
    query: Matriz de consultas [batch, seq_len, d_k]
    key:   Matriz de claves   [batch, seq_len, d_k]
    value: Matriz de valores  [batch, seq_len, d_v]
    """
    d_k = query.size(-1)
    
    # 1. Producto punto entre Query y Key traspuesta
    scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(d_k)
    
    # 2. Aplicar Softmax para obtener pesos de atención (suman 1)
    attention_weights = F.softmax(scores, dim=-1)
    
    # 3. Multiplicar pesos por los valores
    output = torch.matmul(attention_weights, value)
    return output, attention_weights

# --- Ejemplo de uso ---
seq_len, d_k = 3, 4 # 3 palabras, dimensión 4
q = torch.rand(1, seq_len, d_k)
k = torch.rand(1, seq_len, d_k)
v = torch.rand(1, seq_len, d_k)

output, weights = scaled_dot_product_attention(q, k, v)

print("Pesos de Atención (Matriz de enfoque):\n", weights)
print("\nSalida procesada:\n", output)

```

### Desglose de lo que está ocurriendo:

1. **Q, K, V (Query, Key, Value):** Son proyecciones lineales de tus datos.
* **Query:** Lo que busco.
* **Key:** La etiqueta de lo que tengo.
* **Value:** La información real que quiero extraer.


2. **`torch.matmul`:** Realiza la multiplicación de matrices. Esto compara qué tan relevante es cada palabra respecto a las demás.
3. **`math.sqrt(d_k)`:** Es la "escala". Sin dividir por esto, los valores del producto punto crecerían demasiado, enviando al `softmax` a regiones donde el gradiente es casi cero (y el modelo no aprendería nada).
4. **`F.softmax`:** Convierte los números en **probabilidades**. Si la palabra 1 tiene una puntuación alta respecto a la palabra 3, el `softmax` asignará un valor cercano a 1 al peso de esa relación.

### ¿Por qué es vital este script para el proyecto?

Aunque nunca escribirás esta capa a mano en un entorno de producción (ya que usarás `nn.MultiheadAttention` de PyTorch), entender este script es fundamental porque:

* **Interpretabilidad:** Si algún día necesitas saber **por qué** tu modelo clasificó una reseña como "Negativa", puedes extraer estos `attention_weights` y visualizarlos. Podrías ver que el modelo asignó un peso de atención muy alto a la palabra "impurezas" y "cascarilla".
* **Depuración:** Si tu modelo de calidad de arroz no está aprendiendo, saber cómo se calculan estos pesos te permite identificar si hay "problemas de escala" en tus datos.
